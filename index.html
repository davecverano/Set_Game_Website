Game of Set

Instructions

1 to 4 players compete on the same computer. When you spot a set, click your player button, then click the three cards. A correct set earns a point; a wrong one loses a point. The player with the highest score when the deck runs out wins.

A set is 3 cards where, for each attribute (color, number, shading, shape), the cards are either all the same or all different. See Wikipedia for more.

  • New Game reshuffles the deck, deals a new table and resets every score.
  • Hint names one card that is part of a set.
  • Auto Check, when on, deals 3 more cards automatically whenever there is no set on the table.
  • Add 3 Cards deals 3 more cards by hand. Turning Auto Check off and using this button is closest to the real card game.
